# 数学二错题本 · 2012

> 本页记录 2012 年数学二套卷复盘。建议成绩：约 108 / 150。重点不是抄答案，而是记录“触发词 → 第一反应 → 标准方法”。

## 第 2 题：乘积求导与零点贡献

- **知识点**：乘积求导、在特定点判断哪些项为 0。
- **题型**：多个因子相乘，求 (f'(0))。
- **错因**：选择错误；对乘积求导后“哪些项真正留下”判断不够稳。
- **第一反应**：先看每个因子在 (x=0) 的值，找出唯一为 0 的因子；乘积求导时只有对该因子求导的那一项可能非零。
- **标准方法**：不要全展开，利用零因子快速筛项。
- **触发词**：**“乘积很多 + 求某点导数” → 先查零因子，不要硬展开。**

## 第 3 题：充分必要条件与反例

- **知识点**：数列、部分和、有界性、收敛性、充分必要条件。
- **题型**：判断“条件 A 是结论 B 的什么条件”。
- **错因**：没有及时举反例，导致必要性/充分性判断摇摆。
- **第一反应**：先分别检查“(ARightarrow B)”和“(BRightarrow A)”；任何一边怀疑，就立刻造最简单反例。
- **标准方法**：正项条件下，部分和有界可推出级数收敛，从而 (a_n	o0)；反向不成立，可用 (a_n=1/n)。
- **触发词**：**“充分必要” → 两个方向分开证；证不出就找反例。**

## 第 12 题：全微分型微分方程

- **知识点**：全微分、初始条件。
- **题型**：(Mdx+Ndy=0)，可直接凑全微分。
- **错因**：会做，但最后没有把 (y=cdots) 明确写出来，属于收尾失分。
- **第一反应**：看到 (y,dx+x,dy) 就想到 (d(xy))。
- **标准方法**：(y,dx+(x-3y^2)dy=d(xy-y^3)=0)，先得隐式解，再代初值，最后解出题目要求的 (y)。
- **触发词**：**“填空题” → 最后一行必须写成题目空格要求的形式。**

## 第 13 题：曲率 vs 曲率圆圆心

- **知识点**：曲率
  [
  K=rac{|y''|}{(1+y'^2)^{3/2}}
  ]
  与曲率中心公式的区别。
- **题型**：已知曲率，求曲线上的点。
- **错因**：误判为“求曲率圆圆心”，一时想不起圆心公式就放弃；实际题目只需曲率公式。
- **第一反应**：先看问的是“曲率为某值的点”还是“曲率圆/曲率中心”。
- **标准方法**：先用曲率公式解 (x)，再代回原函数求 (y)。
- **触发词**：**“曲率为……的点” → 只求原曲线上的 ((x,y))，不是圆心。**

## 第 14 题：伴随矩阵行列式

- **知识点**：
  [
  |A^*|=|A|^{n-1}
  ]
  以及交换两行使行列式变号。
- **题型**：伴随矩阵与行列式混合计算。
- **错因**：把指数 (n-1) 记成 (n-2)，属于公式记忆性错误。
- **第一反应**：看到 (A^*) 先写三条：
  (AA^*=|A|E)、可逆时 (A^*=|A|A^{-1})、(|A^*|=|A|^{n-1})。
- **标准方法**：先单独算 (|B|) 与 (|A^*|)，再用 (|BA^*|=|B||A^*|)。
- **触发词**：**“(n) 阶伴随矩阵行列式” → 指数永远是 (n-1)。**

## 第 18 题：极坐标二重积分

- **知识点**：极坐标换元、雅可比 (r)、三角积分。
- **题型**：心形线区域上的二重积分。
- **错因**：区域和积分式都列对，最后 (	heta) 积分计算错误；展开后把带 (sin	heta) 的积分算乱。
- **第一反应**：

- **触发词**：**“(sin	heta,F(cos	heta))” → 直接换元。算出 (pi) 时要警觉。**

## 第 19 题：拐点坐标与代回原函数

- **知识点**：常系数微分方程、拐点判定、复合函数。
- **题型**：先求 (f(x))，再求另一条曲线的拐点。
- **错因**：前面基本完成，最后求拐点坐标时代错位置，没有把横坐标代回 (y) 的原表达式。
- **第一反应**：求出拐点横坐标后，最后一步固定写“代回 (y=cdots)”。
- **标准方法**：(y''=0) 只给候选横坐标；还要验证凹凸性改变，并代回原函数得到完整坐标。
- **触发词**：**“求拐点” → 横坐标 + 代回原函数求纵坐标，缺一不可。**

## 第 20 题：不等式证明的构造方向

- **知识点**：函数单调性、常用不等式、构造辅助函数。
- **题型**：证明
  [
  xlnrac{1+x}{1-x}+cos xge1+rac{x^2}{2}.

- **错因**：当时没找到突破口，误以为要往“构造原函数/微分中值定理”方向做。
- **第一反应**：先把复杂项拆开分别压估：
  [

  ]
- **标准方法**：构造
  [
  g(x)=lnrac{1+x}{1-x}-2x
  ]
  用导数判符，再结合余弦基本不等式。
- **触发词**：**“证明复杂和式不等式” → 先拆成两块，找每块熟悉的上下界。**

## 第 21 题：唯一根 + 数列根的极限

- **知识点**：零点定理、单调性、单调有界、数列极限。
- **题型**：先证方程在区间内有且仅有一个根，再研究这些根构成的数列。
- **错因**：只做出了“至少有一个”，没有完成“至多一个”；第二问没有建立 (x_{n+1}) 与 (x_n) 的大小关系。
- **第一反应**：
  - “至少一个” → 端点异号；
  - “至多一个” → 导数同号/严格单调；
  - “根构成数列” → 把 (x_n) 代入 (f_{n+1}) 比较。
- **标准方法**：由 (f_{n+1}(x_n)>0=f_{n+1}(x_{n+1})) 且 (f_{n+1}) 递增，得 (x_{n+1}<x_n)；再用 (x_n>1/2) 得单调有界。
- **触发词**：**“有且仅有” = 存在性 + 唯一性，两段必须都写。**

## 第 22 题：无穷多解的判定

- **知识点**：线性方程组解的结构、秩、增广矩阵。
- **题型**：含参数非齐次方程组何时有无穷多解。
- **错因**：概念不够牢，只根据 (|A|=0) 留下 (a=pm1)，没有继续检查相容性，误把 (a=1) 也算入。
- **第一反应**：(|A|=0) 只是“可能不是唯一解”，还必须判断：
  [
  r(A)=r(A|eta)<n
  ]
  才是无穷多解。
- **标准方法**：候选参数先由 (|A|=0) 得出，再逐个代入增广矩阵检查秩。
- **触发词**：**“无穷多解” → 绝不能停在 (|A|=0)，必须查 (r(A)=r(A|eta)<n)。**
